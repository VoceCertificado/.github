## Projetos em destaque

### [TXT Color](https://github.com/VoceCertificado/txtcolor)

Extensão para VS Code, Kiro e outras IDEs compatíveis que adiciona destaque visual a arquivos de texto, logs e arquivos de configuração.

- Destaque de níveis como `ERROR`, `WARN`, `INFO` e `SUCCESS`.
- Suporte a arquivos `.txt`, `.log`, `.ini`, `.conf`, `.cfg`, `.env`, `.properties` e `.toml`.
- Disponível no [Open VSX Registry](https://open-vsx.org/extension/VoceCertificado/txt-color) e no [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=VoceCertificado.txt-color).

### [Strands Agents para auditoria AWS](https://github.com/VoceCertificado/strands-agents-auditoria-aws)

Laboratório que utiliza Strands Agents e Amazon Bedrock para inventariar e auditar recursos de uma conta AWS.

O agente consulta instâncias Amazon EC2, volumes Amazon EBS, endereços IPv4 públicos e NAT Gateways. Em seguida, organiza as descobertas e valida a conclusão da auditoria.

### [Consultar custos AWS pelo CloudShell](https://github.com/VoceCertificado/aws-cloudshell-consulta-custos)

Exemplo prático para consultar os custos do mês atual de uma conta AWS, agrupados por serviço, diretamente pelo CloudShell.

O projeto apresenta o comando para copiar e executar, um exemplo do resultado e orientações para interpretar os valores retornados.

Confira também o artigo [Como consultar os custos da AWS pelo CloudShell](https://www.vocecertificado.com.br/consultar-custos-aws-cloudshell/).
